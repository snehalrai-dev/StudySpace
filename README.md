
# StudySpace 📚

A student productivity web app designed to help students organize tasks, focus on study sessions, and track daily progress.

## ✨ Features

- **Task Management** — Add, complete, and delete tasks.
- **Task Persistence** — Tasks remain saved after refreshing the page.
- **Focus Timer** — Choose a study duration and start, pause, resume, or reset the timer.
- **Progress Tracking** — View completed tasks, pending tasks, and overall completion percentage.
- **Daily Summary** — Get a quick overview of your daily task progress.
- **Responsive Design** — Use the dashboard on desktop and smaller screens.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

## 🚀 Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
4. Start adding tasks and planning your study sessions!

## 🎯 Project Goal

StudySpace is a learning project built to practice front-end web development, JavaScript, DOM manipulation, browser storage, and responsive UI design.
